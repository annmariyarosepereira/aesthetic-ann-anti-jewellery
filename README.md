# 💎 Aesthetic Ann Jewellery

Aesthetic Ann Jewellery is a full-stack MERN e-commerce web application designed for browsing, purchasing, and managing jewelry products online.  
The platform provides a smooth shopping experience with user authentication, product catalog browsing, shopping cart functionality, checkout, order history, and product reviews.

---

## 🚀 Features

### 👤 User Features
- User Signup & Login with JWT authentication
- Secure user profile management
- Browse jewelry products
- View product details with images
- Add products to shopping cart
- Modify cart quantity
- Checkout and place orders
- View order history in dashboard
- Write product reviews

### 🛍️ Shopping Features
- Product catalog with categories
- Product detail page
- Sale price support
- Stock availability tracking
- Shopping cart system
- Order summary before checkout

### 📦 Order Management
- Place new orders
- View previous orders
- Track order status
- Order history dashboard

### ⭐ Additional Features
- Customer product reviews
- Jewelry care tracker
- Custom jewelry builder
- Responsive modern UI
